Getriebe-Generator

Wellen aus dem Wellen-Generator senkrecht auf eine Ebene stellen; was kämmt oder mit einem Riemen läuft, legt die Abstände fest. Aus den Lagern entsteht ein Gestell aus Platten: Ringe um die Lager, Stege dazwischen, Schicht für Schicht.

Beispiele

Schichten von der Seite

Wellen von links auf die Ebene ziehen oder anklicken. Nahe an einem passenden Rad rasten sie im Eingriff ein, im Winkelraster um das Partnerrad; sonst im mm-Raster. Alt schaltet das ab. Unten die Schichten als Bänder: verschieben, Kanten ziehen. Entf löscht, Strg+Z macht rückgängig.
